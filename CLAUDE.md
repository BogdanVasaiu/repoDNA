## Project Overview

 I made a repo, its a little project that scans CODE projects and analyses it with ollama and it creates a context file useful for not doing it manually. 
There is a beatiful frontend and easy to use, just download and you are ready to go “node main.mjs”.
Compatible with windows, linux and mac.
Just needs nodejs and ollama to work, the ui helps a lot the user in every step.
data will always remain cached so next time will be immediate.
Step 1: it checks nodejs and ollama are up.
Step 2: You can add and save your projects with a description to help the process.
Step 3: There is an algorithm that suggests you to not include some foulders or some extensions that may be not useful, and user can add his custom in that algorithm.
Step 4: User can choose the precision, the ollama model and if to not scan unchanged files.
There will be also a table updated often to show people models that they can run for this task based on the quality, hardware needed and speed.
Step 5: user can choose the cli for the output from a list, and there will be a summary be for processing them.
In the end there is a progression ui where it shows the files content in trasformed markdown live, logs, its possible to retry a file and staff like that.
The output will be saved direcly in the project selected…
landing page that repodna.com.
