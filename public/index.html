Your Installed Models About this list Every model that's currently pulled into your Ollama instance, plus any Ollama Cloud models available to your account. How tok/s is calculated It's the average output tokens per second across your past runs with that model — higher is faster. Local — measured from Ollama's own eval_count / eval_duration stats. Pure model speed, no network involved. Cloud — measured against wall-clock time, so it includes network latency. Numbers are realistic for you but not directly comparable to the local figure. A dash (—) means you haven't run that model yet, so there's no average to show.

Copy it, run it in your terminal, and the model shows up in Your Installed Models above. Reading the columns Size — disk footprint of the model weights. VRAM (local only) — minimum GPU memory recommended to run it smoothly. If you're short, the model spills to RAM and slows down. Context — max tokens the model can hold in one prompt. Larger = it can see more of your file at once. Quality — how good the output tends to be on code-analysis tasks (our subjective rating). Speed — expected generation speed. How the run works Files are analyzed one by one. Once the run finishes — or you stop it — the context file is written directly into your project. Each file's result opens as a tab on the right. From there you can retry the analysis for that file, or edit the result in place. ⚠ Don't edit the generated file in your project With Smart Update on, the next run continues from the cached copy — any edits you make to the file on disk will be overwritten. Make changes here in the UI instead.

Files Files panel A live view of every file in this run — similar to GitHub's Changed Files tab. The change badge tells you why the file is here (new, modified, retried…) and the status icon tells you where it is in the run (pending, running, done, failed). Change badges + Created — new file since the last run. ~ Modified — file content changed since the last run. ↩ Re-added — previously excluded, now included again. − Removed — dropped from the analysis. ↺ Retried — re-run manually from this panel. ✎ Edited — result was edited directly in the UI. Status icons · Pending — queued, waiting its turn. ⟳ Running — currently being analyzed (purple if it's a retry). ✓ Done — analysis finished, result available in the tabs. ⚠ Error — analysis failed. Hit ↺ retry on the row to try again. ✕ Deleted — removed from the project since the last run. Use ↺ retry on a row to re-analyze just that file.
